# DA.AllergyJournal
Android-App for documenting your allergy reactions, based upon the paperjournal I got from the doctor.

# Planning
## Introduction
### Purpose
Tool for documenting allergy reactions over a day.
### Goal
Goal is it to create an Android-App for documenting your allergy and for printing the overview, to present it to the doctor.
